## 运行方式

无需安装任何依赖或构建步骤：

```bash
# 方式一：直接双击任意 index.html

# 方式二：用本地服务器（部分页面依赖模块加载时更稳）
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000/玛丽跳deepseekv4-1/index.html
```

## 说明

- 所有游戏均为**纯前端实现**，多数使用 Canvas 2D + Web Audio 程序化合成音效，不依赖外部图片/音频资源。
- `.gitignore` 已排除 macOS 系统文件（`.DS_Store`）与工具本地的机器配置（`.claude/`、`.workbuddy/`）。
